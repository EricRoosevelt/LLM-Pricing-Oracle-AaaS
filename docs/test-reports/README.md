# Test Reports

This directory stores manual validation reports and other non-runtime test evidence.

Naming convention:

- `YYYY-MM-DD-<scope>-<test-type>.json`
- Use lowercase words separated by hyphens.
- Keep raw terminal output out of the repository unless it is needed to reproduce a defect.

Current reports:

- `2026-05-15-agent-routing-control-plane-manual-runbook.json`: manual runbook closure for the Agent Routing Control Plane validation cycle.
